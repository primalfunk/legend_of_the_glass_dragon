# Project documents

This directory preserves the governing documents for the clean-slate native Android generation of Legend of the Glass Dragon.

- `IIP.txt` — Native Android Initial Implementation Plan, version 0.1.
- `work_orders/LGD-001_NATIVE_FOUNDATION_AND_FIRST_ANSI_SHELL.txt` — authorized first work order.
- `work_orders/LGD-002_CHARACTER_CREATION_PERSISTENT_PLAYER_SAVE_AND_FIRST_REAL_TOWN_STATE.txt` — authorized character/save work order.
- `work_orders/LGD-003_FOREST_COMBAT_PROGRESSION_AND_FIRST_COMPLETE_GAME_DAY.txt` — authorized first-playable-loop work order.
- `work_orders/LGD-003_CONTROLLED_DEFEAT_PHYSICAL_TRAINING_AND_PROGRESSION_BALANCE.txt` — authorized controlled-defeat and campaign-balance qualification work order.
- `work_orders/LGD-004_SIMULATED_ADVENTURER_COMMUNITY_RANKINGS_DAILY_NEWS_AND_WORLD_ADVANCEMENT.txt` — authorized simulated-community work order.
- `work_orders/LGD-005_SHOPS_BANK_EXPANDED_INN_EQUIPMENT_ECONOMY_AND_ADVENTURER_CHALLENGES.txt` — authorized equipment-economy and adventurer-challenge work order.
- `work_orders/LGD-007_ANSI_VISUAL_IDENTITY_AND_MINIMAL_AUDIO_PASS.txt` — authorized ANSI production-identity and bounded audio work order.
- `work_orders/LGD-008_GLASS_CHRONICLE_AND_DAWN_BRIEF.txt` — authorized structured Chronicle and Dawn transition work order.
- `work_orders/LGD-009_DRAGON_SEASON_AND_CAMPAIGN_ENDGAME.txt` — authorized finite Dragon Season and campaign-endgame work order.
- `work_orders/LGD-010_MAIN_MENU_AND_PRODUCT_WRAPPER.txt` — authorized product-wrapper, Main Menu, settings, and completed-season work order.
- `reports/LGD-001_COMPLETION_REPORT.md` — implementation and qualification evidence.
- `reports/LGD-002_COMPLETION_REPORT.md` — character creation, persistence, and physical-device qualification evidence.
- `reports/LGD-003_COMPLETION_REPORT.md` — first playable combat/day-loop implementation and qualification evidence.
- `reports/LGD-004_COMPLETION_REPORT.md` — simulated community, rankings, news, and soak-test evidence.
- `reports/LGD-005_COMPLETION_REPORT.md` — equipment, banking, rivalry, challenge, and physical-device qualification evidence.
- `reports/LGD-007_COMPLETION_REPORT.md` — ANSI art, audio import, lifecycle, phone/tablet, and build qualification evidence.
- `reports/LGD-008_COMPLETION_REPORT.md` — structured transition, Chronicle/Dawn visibility, restore, and multi-day device evidence.
- `reports/LGD-009_COMPLETION_REPORT.md` — Dragon escalation, player/NPC endgame, 25-season cohort, conclusion, and physical campaign evidence.
- `reports/LGD-010_COMPLETION_REPORT.md` — product wrapper, state-sensitive Main Menu, season archive, audio preferences, icon/splash, and device evidence.
- `assets/LGD-007_AUDIO_IMPORT.md` — Principal audio source-to-package mapping and the bounded click compatibility conversion.
- `assets/LGD-010_MUSIC_PROVENANCE.md` — embedded recording metadata and release-clearance status for all packaged audio.

- `work_orders/LGD-011_CAMPAIGN_SIMULATION_AND_BALANCE_CHARACTERIZATION.txt` — authorized deterministic whole-campaign measurement work order.
- `reports/LGD-011_COMPLETION_REPORT.md` — cohort architecture, baseline freeze, headline results, and qualification disposition.
- `reports/evidence/LGD-011/` — full Principal report plus per-season, per-day, enemy, summary, and outlier machine-readable evidence.
- `reports/LGD-011A_COMPLETION_REPORT.md` — first targeted balance experiment and recharacterization.
- `reports/LGD-011B_COMPLETION_REPORT.md` — Principal-range rebalance and accepted 5,000-season campaign baseline.
- `reports/LGD-012_RELEASE_QUALIFICATION_REPORT.md` — Android release packaging, lifecycle/save/device, provenance/signing, artifact, and MVP-closure evidence.

The previous web application may inform content or game design, but remains reference-only and is not an architectural or runtime dependency of this repository.
